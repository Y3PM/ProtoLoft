# 双色图标使用审查 · 2026-11-25

结论：继续采用「静止线性、交互时双色」的方式合理，功能图标集中使用品牌蓝、危险操作使用红色，也适合当前浅色工作台。优先修复状态恢复与可读性，再补充少量语义明确的图标。本轮仅审查，未改运行代码、版本、数据库或部署。

## 范围与来源

- 本地基线：HEAD `665a99d` + 当前未提交工作区，运行版本 3.1.11。审查 `assets/js/duo-icons.js`、相关 CSS、PHP 视图及动态模板。
- 提取到 29 个图标定义、104 处静态引用；没有未定义引用或完全未使用的定义。104 是源代码引用点数量，不代表页面同时渲染 104 个实例。
- 核对上游 [README](https://github.com/kubai087/kubai-icons/blob/master/README.md)、[双色规范](https://github.com/kubai087/kubai-icons/blob/master/styles/duotone/GUIDE.md)、[动画实现](https://github.com/kubai087/kubai-icons/blob/master/styles/duotone/motion.mjs)。当前本地动画的 480ms、逐段增加 110ms、移开 360ms 与上游节奏一致；复杂图标最长 920ms，不能据此判为实现错误。
- 在隔离 PHP 8.3.20 临时安装、合成账号及项目上，用内置浏览器检查 1280×720 工作台、分享弹窗、控制中心团队页与分享页。未操作真实站点或发送 Webhook。

## 保留与补充范围

- 保留现有品牌蓝、主按钮白色图标和删除红色的分工。动态表格中的删除图标已通过委托装配，键盘聚焦为红色 `rgb(220,38,38)`；不是所有动态内容都存在丢失问题。
- 原生浏览器单文件方案与本地 SVG 资产符合项目零构建依赖；发版白名单已包含 `duo-icons.js`，不建议接入完整组件框架或全量图标库。
- 补充优先级：人像/新增成员；复制成功可复用已有 `circle-check`。关闭、展开箭头、权限勾选等结构与状态符号维持简洁静态。
- 若继续优化动效，优先给复制、刷新、编辑等高频小按钮使用精简版本；低频功能入口可保留原库完整动作。这是产品取舍，不把上游规定的时长列作缺陷。
- 现有代码已支持键盘聚焦触发和减少动态效果。后续实施时补充 hover 与 focus 同时存在、禁用/加载、连续进入移出、重新渲染后的装配回归。
