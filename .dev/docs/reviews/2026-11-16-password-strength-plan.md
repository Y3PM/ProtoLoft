# ProtoLoft 密码强度检测评估与优化清单

评估基线为 ProtoLoft `3b2798b` 和 `com.y3pm.www/tools/genpass` 的强度检测提交 `e46258a`。接入范围为 zxcvbn-ts 浏览器评分能力。PHP 统一检查新密码的长度，评分提供可忽略的提示。以下保留评估样本和实施后的验收记录。

## 原方案评估

genpass 在浏览器加载本地 `core`、`language-common`、`language-en`，同步估算 0–4 分。目前只使用 `score` 显示五档。三份脚本合计 1,571,918 字节，分别 gzip 后合计 732,555 字节。这是文件压缩估算，实际传输量取决于服务器。评分脚本适合离线部署，须按需加载，并核实具体发行版本与各词库许可证。现有打包脚本中未见版本标记。

下表用 Node `vm` 加载原有三份浏览器脚本，按 `main.js` 的配置初始化。两次初始化分别测试原版词库和加入站点名的词库，样本均为合成输入。

| 样本 | 原版 | 加入站点与组织名 |
| --- | ---: | ---: |
| `123456789012345` | 1/4 | 1/4 |
| `qwertyuiopasdfgh` | 1/4 | 1/4 |
| `orbit cedar paper violin` | 4/4 | 4/4 |
| `ProtoLoft2026!` | 4/4 | 2/4 |
| `Northpeakstudio2026!`（虚构组织名） | 4/4 | 2/4 |

ProtoLoft 目前接收中文等多字节输入。汉字和 emoji 样本用于检查字符数、字节数和表单表现。首期评分验收以英文字母、数字、符号及英文短语为主。

现有 bundle 的 `extendUserInputsDictionary` 会把参数追加到共享词库。实测连续三次传同一值，词库从 2 项增至 5 项。接入时如果使用站点名和邮箱前缀辅助评分，按编辑对象和上下文隔离实例或重置对应词表。[上游实例 API 迁移说明](https://zxcvbn-ts.github.io/zxcvbn/guide/migration/)

## 优化清单

- [x] **P0 · 统一长度校验。** 新密码至少 6 个字符，上限沿用 64 UTF-8 字节。英文、数字与常见半角符号相当于 6–64 位。前后端统一口径，多字节字符超出上限时给出清楚提示。长度符合即可保存，字符组合由用户决定，并支持空格和短语。改动前 PHP 按 `strlen` 计数，页面 `maxlength` 按 UTF-16 代码单元计数。保留 bcrypt 可处理的长度上限，避免截断。[PHP 密码哈希文档](https://www.php.net/manual/en/function.password-hash.php)
- [x] **P0 · 覆盖六个写入入口。** 安装时创建主管理员、访客申请、管理员新增成员、管理员为成员设新密码、个人改密、邮件重置共用 PHP 长度校验。覆盖访客申请的独立登录页与工作台弹窗。编辑成员时密码留空仍表示保持当前密码，已有账号继续按原凭据登录。
- [x] **P1 · 在新密码框下嵌入反馈。** 输入后显示等级和最多一条建议，低分也可以保存。使用明确的文本状态和适度的 `aria-live` 通告。保留密码遮蔽与查看控件，支持密码管理器、粘贴和自动填充。登录、旧密码、确认密码、分享口令、SMTP 授权码及移交确认框无需评分。评分库加载失败时可正常按长度提交。
- [x] **P1 · 按需加载与隐私。** 固定可追溯的 zxcvbn-ts 静态包并保留其许可证和词库归属。仅在新密码表单出现后加载，登录首屏及普通工作台浏览省去词库请求。离线部署无需构建依赖。评分数据留在浏览器内存，同一表单仅评分当前输入。密码只随原有 HTTPS 提交流向业务接口，评分流程禁用网络查询、日志、持久存储和采集。新脚本和词库加入 `.dev/export_release.py` 白名单并验证导出的安装和使用路径。[zxcvbn-ts 按需加载建议](https://zxcvbn-ts.github.io/zxcvbn/guide/best-practices/)
- [x] **P2 · 验收六条写入链路。** 临时安装的 HTTP 回归覆盖直接 API 提交、5/6 字符、64/65 字节、符合长度的低分密码可保存、现有密码登录、管理员编辑留空、邮件令牌可重试且成功后仅能使用一次。浏览器覆盖两个注册入口、安装与找回页、个人及管理员表单、批量输入、移动端和评分脚本加载失败。发布包实测包含新增资源。

## 实施与复核

- 采用 zxcvbn-ts 官方浏览器发布包，core 和 language-common 固定为 3.0.4，language-en 固定为 3.0.2。三份传输文件约 1.71 MB，独立 gzip 估算合计约 0.80 MB。首次有效输入才加载。评分加入产品名，输入及评分结果仅使用浏览器内存。发布包包含 MIT 与词库归属说明。[zxcvbn-ts 上游项目](https://github.com/zxcvbn-ts/zxcvbn)
- PHP 8.3.20 全量测试命令为 `python3 -B .dev/tests/run_all_tests.py --php /Users/yyy/.local/bin/php`，通过 25 套、1,099 项可识别断言。新增密码策略专项 19 项和邮件重置边界断言，覆盖 5/6 个字符、64/65 字节、存量登录、低分密码保存、管理员编辑留空及重置链接可重试和单次使用。
- Browser 插件未提供，使用本机 Playwright 与 Chrome。临时发布包专项命令为 `python3 -B .dev/tmp/password-strength/browser_probe.py`，25 项检查通过。实际打开安装、独立注册、工作台注册弹窗、管理员新增及编辑成员、个人改密和邮件重置字段。验证评分按需加载、低分提交、拦截评分资源后正常提交、超长输入后的纠正反馈，以及改密后重新登录。桌面 1440×1000、手机 390×844，已观察截图。
- 导出扫描通过，临时 ZIP 含 67 个生产文件，逐项确认新校验器、评分桥接脚本、三个发布包和许可文件，并从导出目录完成全新安装。浏览器和 PHP 日志无应用错误。PHP 7.0、真实密码管理器和生产 FTP 待验证。
