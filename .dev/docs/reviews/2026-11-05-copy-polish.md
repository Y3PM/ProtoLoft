# 文案与表单整理 · 2026-11-05

用户在问题清单之后授权直接优化。本轮沿用现有 Linear 浅色工作台，不改品牌资产、口号、控制中心结构或既有自动保存策略。

## 实施

- 必填字段标题标星；选填统一为标题旁的灰色“选填”，不混入平台名称或放在占位文字里。已有默认值的角色/打开方式不再单独强调必填。项目/链接名称动态切换保留星号。
- 注册、改密增加固定标签，姓名、邮箱、部门或职务等同字段名称收口；统一管理员/主管理员/协作者/审阅人及停用状态。个人设置的所有者徽标与侧栏一致。
- 使用“版本名称”“身份水印”“系统时区”等实际含义清楚的名称；交接只称交接负责项目，不暗示改写批注作者；批注空状态不评价团队工作表现。危险操作按钮指明对象。
- 项目、成员、系统、个人通知复用 38px 表单行和按钮；分享表单移除 30/36px 零散尺寸；个人设置使用 M 档 540px。保留原控制中心已有的 32px 工具栏和小型提示操作的 28px 按钮。
- 项目基本资料表单移除保存不采用的协作者/局部水印选项。前端不再固定发送空值，后端在字段缺省时保留已有配置，显式提交时仍支持原有授权更新逻辑。
- 链接地址前端按类型切换必填，服务端拒绝空值；有效负责人只列出已启用的管理员/协作者。切换新建/项目/链接时解除隐藏输入的 required，避免阻塞其他表单。
- 重复注册根据待审/启用/其他状态分别提示等待、登录或联系管理员；不改变邮箱域名限制。
- 选择自定义分享截止日期时显示固定标签并启用 required；群通知同步更新日志的 required/标识。
- 分享复制只在现代接口或降级复制确认成功时显示已复制，失败显示手动复制提示，清理临时元素。
