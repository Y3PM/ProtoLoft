## 根因与修复

1. **两个内容区同时显示**：`.anno-body` 设置 `display:flex !important`，覆盖 JS 的 `style.display='none'`。上版未决虽然显示历史面板，当前版列表仍露出。现在两个面板都使用 `hidden`，并以专属 CSS 规则保证真正隐藏。
2. **状态重置不完整**：切项目/版本清空并隐藏了历史面板、移除历史 Tab 高亮，但没有同步重置 `statusFilter`；`renderAnnotationList()` 在 previous 状态提前返回，旧的当前版 DOM 又没有清空。现在项目边界清空旧列表 DOM 并回到全部，同项目版本切换统一同步 Tab、列表和输入区。
3. **历史请求只有上下文守卫**：同一个上下文中离开/重新进入历史视图，早先请求仍可能覆盖较新请求。历史读取新增独立序号，并同时校验项目、版本、上下文代际及当前筛选。关闭或离开历史视图时旧请求失效，重新打开时重新读取。
4. **空项目误采旧 iframe**：版本为 0 时原逻辑可能从仍承载旧原型的 iframe 反推版本、恢复输入就绪状态。现在项目/版本由宿主选择明确指定；无版本项目不请求默认版本，也不从旧 iframe 收养版本号。

| 操作 | 修复后的行为 |
| --- | --- |
| 抽屉打开后切项目 | 清空旧内容，回到新项目当前版的全部状态；本页/全部范围偏好保留 |
| 同项目切版本，普通状态筛选 | 保留状态筛选，读取新版本的批注 |
| 同项目切版本，上版未决 | 新版本存在上一版则保持该 Tab，并重新读取相应上一版 |
| 切到最早版本 | 隐藏上版未决入口，回到当前版全部 |
| 切到无版本项目 | 清空上下文、输入禁用，保留宿主既有自动收起行为 |
| 切到外链 | 历史入口隐藏，读取外链自己的无版本批注 |
| 连续请求或慢响应 | 只有最新且仍属于当前上下文/筛选的结果可以改历史面板 |
| 引用到本版 | 回到当前版列表，聚焦实际返回的新批注，恢复输入区 |

## 已确认的轻量做旧样式

- 按原批注 `created_at` 计算实际经过天数，UTC 字符串与现有批注时间采用同一解析函数；查看、切版不会改变创建时间。
- 0–7 天为浅灰纸白，8–30 天为淡米纸色，31 天以上稍暖、边线略深，设置强度上限。
- 版本来源与相对天数在同一行，页面名和原文完整换行；日期缺失时不伪造年龄。
- 所有新增色值集中在 `:root` 的 `--archive-paper-*` / `--archive-edge-*` 令牌，操作继续消费公共按钮基础类与 `.btn-sm`。
- 正文和按钮保持清晰、不随年龄降低透明度；正文/时间元数据使用现有 `--text-2`，三档纸面计算对比度约为 6.77 / 6.55 / 6.22。
- 历史面板占据抽屉剩余空间独立滚动，移除原 220px 限制及与当前列表并存的底部空状态。历史针对整个上一版本，本页/全部范围按钮在该视图禁用，返回当前版后恢复。
