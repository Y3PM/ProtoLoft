# 立象原型 · 全景测试用例矩阵与规范指南 (Test Matrix)

> **版本**：v3.8.0  
> **核心使命**：立象以尽意 · 披图而同心（让想法可见，让协作清晰。） / *Give ideas a shared home.*  
> **适用范围**：本文档为立象原型（ProtoLoft）系统的全模块自动化回归测试与人工验收基准，涵盖 8 大核心领域、40+ 业务细分场景与 120+ 详细测试断言。

## 1. 测试环境与执行约定

- **运行沙箱**：所有自动化测试均在独立的临时目录（如 `/tmp/protoloft-test-xxxx/`）克隆运行，配合临时 SQLite 数据库执行，严禁直连生产或工作区数据。
- **依赖说明**：
  - PHP 7.0+（支持 PHP 8.x），必须启用 `pdo_sqlite`、`zip`、`mbstring` 扩展；
  - Python 3.8+（自动化测试执行器与 HTTP 回归套件）；
  - Node.js 18+（前端模拟 DOM 互斥与逻辑测试）。
- **角色体系与预置账号**：
  - `Owner`（平台超级管理员）：拥有全站最高控制权（移交所有权、全局配置、审批成员、删除任意项目/版本）。
  - `Editor`（协作发布者）：允许新建项目、管理自己负责的项目、发布新版本、设置分享。
  - `Viewer`（审阅访客）：仅拥有只读权限，可预览授权项目、发表与查看批注，严禁下发管理面板与执行写操作。
  - `Guest`（未登录外部访客）：受控访问公开分享页或登录入口，受口令与过期时间保护。

## 3. 验收标准与交付清单

1. **自动化执行**：所有用例必须通过自动化脚本（Python / Node.js）进行真实 HTTP 回归验证；
2. **零副作用**：自动化脚本测试结束后，必须完全清理临时进程、端口、临时目录与测试数据；
3. **缺陷容忍度**：全量测试套件执行通过率必须达到 **100%**。
